# Thư viện Kỹ năng CSS Giao diện Web (CSS Skills Library)

Thư mục này chứa 3 bộ kỹ năng (Skills) thiết kế CSS chuyên sâu dành cho website du lịch miệt vườn:

| Kỹ năng (Skill) | Đường dẫn | Mô tả chính |
| :--- | :--- | :--- |
| **1. Modern UI Styling** | [`skills/modern-ui-styling/SKILL.md`](./modern-ui-styling/SKILL.md) | Bảng màu sinh thái tự nhiên, hệ thống Typography, đổ bóng mềm mại đa tầng và quy tắc bố cục UX/UI. |
| **2. Tour Card Components** | [`skills/tour-card-components/SKILL.md`](./tour-card-components/SKILL.md) | Mẫu thẻ tour hoàn chỉnh, nút bấm gradient, nhãn Sale nổi bật, phân trang bo tròn hiện đại. |
| **3. CSS Animations & Effects** | [`skills/css-animations-effects/SKILL.md`](./css-animations-effects/SKILL.md) | Kính mờ (Glassmorphism), shimmer tải trang, hiệu ứng hover zoom ảnh và micro-interactions. |

## Cách sử dụng
Bạn có thể mở từng file `SKILL.md` trong VS Code để xem mã mẫu và áp dụng trực tiếp vào `layout.css`, `components.css` hoặc yêu cầu tôi áp dụng bất kỳ thành phần nào vào website cho bạn!
